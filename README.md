# Hailemichael Solomon — Cybersecurity Portfolio

Static site: open `index.html` or deploy the folder to Netlify / Vercel / GitHub Pages.

## Add your photos
Drop images in `assets/` using these exact names (jpg/png both work if you edit the filename in index.html):
- `assets/profile.jpg` — hero portrait (square)
- `assets/projects/sqli.jpg`, `ids.jpg`, `wealthwise.jpg`, `portscan.png`, `speech.png` — 16:9 screenshots

Until a file exists, a styled placeholder shows instead.

## Share preview
After deploying, replace `https://YOUR-SITE.netlify.app` in `index.html` (3 places in the head) with your real site address.
